# 🌍 AfriTalent — Plateforme de Freelances Tech en Afrique

**Projet Semestre 2 — [khadidiatou coly] — [L1IAGE]**

---

## 📖 Description

AfriTalent est un site vitrine pour une plateforme fictive de mise en relation entre freelances tech africains et entreprises. Le site présente la plateforme, ses fonctionnalités, ses tarifs et des profils de freelances.

Ce projet a été réalisé dans le cadre du cours de développement web (Semestre 2).

---

## 🛠️ Technologies utilisées

- **HTML5** — Structure sémantique des pages
- **CSS3** — Mise en page (Flexbox, Grid, Bento Grid), animations, responsive design
- **Bootstrap 5** — Grille, composants (navbar, carousel, accordion, cards)
- **JavaScript Vanilla** — Interactivité (dark mode, compteurs, filtres, validation)
- **Bootstrap Icons** — Icônes
- **Google Fonts** — Poppins (titres) + Open Sans (texte)
- **Git & GitHub** — Versioning et déploiement

---

## ✅ Fonctionnalités principales

1. **Dark Mode** — Bascule clair/sombre, sauvegardé dans localStorage
2. **Compteurs animés** — Les chiffres s'animent au scroll (IntersectionObserver)
3. **Filtrage dynamique** — Les freelances se filtrent par catégorie sans rechargement
4. **Validation de formulaire** — Vérification de tous les champs avec messages d'erreur
5. **Navbar dynamique** — Change de style au scroll
6. **Bouton retour en haut** — Apparaît au scroll vers le bas
7. **Animations fade-in** — Les sections apparaissent en fondu au scroll

## 🚀 Comment lancer le projet localement

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/khadidiatouc125l-gtm/coly-khadidiatou-AfriTalent.git
   ```

2. Ouvrez le dossier du projet :
   ```bash
   cd coly-khadidiatou-AfriTalent
   ```

3. Ouvrez `index.html` dans votre navigateur (clic droit → Ouvrir avec → Navigateur)

Aucune installation supplémentaire n'est nécessaire. Toutes les dépendances sont chargées via CDN.
